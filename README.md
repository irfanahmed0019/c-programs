# c-programs

- 8(d) Read an array; separate odd and even integers into different arrays - [oddeven.c](programs/oddeven.c)
- 9(a) Linear search - [linearsearch.c](programs/linearsearch.c)
- 9(b) Binary search - [binarysearch.c](programs/binarysearch.c)
- 10(a) Bubble sort - [bubblesort.c](programs/bubblesort.c)
- 10(b) Selection sort - [selectionsort.c](programs/selectionsort.c)
- 10(c) Quick sort - [quicksort.c](programs/quicksort.c)
- 11(a) String operations using string-handling functions - [stringfunctions.c](programs/stringfunctions.c)
- 11(b) Number of words and vowels in a string - [wordsandvowels.c](programs/wordsandvowels.c)
- 12(a) Read and display a two dimensional array - [array2d.c](programs/array2d.c)
- 12(b) Transpose of a matrix - [transpose.c](programs/transpose.c)
